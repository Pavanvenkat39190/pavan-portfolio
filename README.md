# Pavan Portfolio V1

Premium/futuristic React portfolio starter for Bollikonda Pavan Venkat Goud.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Build

```bash
npm run build
```
